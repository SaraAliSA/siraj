Siraj Hackathon Core Objective

Build a stable working prototype of Siraj, an Arabic RTL AI financial advisor. Deliver a clear, high-impact product story:

فهم المال ⟵ اسأل سراج ⟵ احصل على البصيرة ⟵ تأكيد إجراء آمن

🎯 Feature Priority Matrix

Must Have Required for Final Demo
  • Arabic RTL dashboard
  • Financial KPI cards & Basic charts
  • Transaction list & Expense categories
  • Siraj AI chat with simple intent detection
  • Mock API, mock data, and transfer confirmation flow
Should Have Important if time allows
  • Financial health score
  • Savings recommendation
  • Reports page
  • Light / dark mode
  • UI polish & improved spacing/copy
Nice to Have Beyond MVP (Build only if ahead)
  • Seasonal spending prediction
  • Unused subscription detection
  • Real authentication & Real banking API integration
  • Advanced analytics & prediction

📅 Daily Hackathon Schedule

1
Day 1: Foundation

Goal: Setup, MVP confirmation, base layout & mock data setup.

  • Setup: Repo setup, branch strategy, dependencies.
  • Frontend: RTL page layout, sidebar, page shells.
  • Backend/AI: Mock database setup, chat UI.

Checkpoint: Merge all branches, fix setup issues, keep main working.

2
Day 2: Core Prototype

Goal: Connect dashboard UI, build AI flow and transfer confirmation flow.

  • Frontend: KPI cards, charts, transaction list.
  • AI/Backend: Intent detection, mock transfer API, response template.
  • Product: Demo flow script, presentation slides draft.

Checkpoint: Midday & evening merges. No large unmerged branches overnight.

3
Day 3: Polish and Demo

Goal: UI Polish, Bug Fixes, Pitch rehearsals, and packaging.

  • QA: Fix all UI/API issues and flow edge cases.
  • UX: Color improvements, spacing, Arabic spelling.
  • Pitch: Rehearse full demo at least 3 times.

End of Day 3 Deliverables:

  • Stable prototype deployed
  • Final presentation slides
  • Practiced demo with backup flow

⚡ Recommended Implementation Order

🔗
Critical Path Sequence
  1. Mock Data Preparation: Create sample accounts, transaction lists, categories (Day 1).
  2. Backend API: Prepare FastAPI mock routes for transactions and summaries.
  3. Dashboard UI: Connect frontend pages to the API endpoints.
  4. AI Chat UI: Build conversational interface window.
  5. Intent Detection: Create logic matching questions to categories.
  6. Transfer Flow: Integrate transfer requests with confirmation dialogues.
  7. Integration & QA: Full cycle end-to-end testing of the story.
  8. Rehearsal: Practice running through the demo scripts.

⚠️ Risks and Blockers

Risk Impact Mitigation Strategy
Scope Creep / Over-building High Strictly stick to the Must Have list first. Freeze features early.
AI/LLM Latency & Failures Medium Use simple rule-based intent matching & mock local templates as a backup.
Backend / Frontend mismatches Medium Define API schemas and response formats before writing code.
Arabic RTL Layout Glitches Medium Start testing in Arabic right-to-left layout from Day 1.
Demo Day Network Failure High Prepare local offline mock responses and pre-record a backup video demo.

🎬 Demo Story Walkthrough

Use this clear, Judge-friendly story flow to showcase peak value in 3 minutes:

1. Open Dashboard: Show financial status summary cards, expense distribution and latest transactions.
2. Ask Spending: Ask Siraj: وين راحت فلوسي؟
3. Explaining Spending: Siraj responds explaining budget consumption categories in natural Arabic.
4. Trigger Action: Ask Siraj: أبي أحول
5. Confirm Safety: The UI displays a secure transfer slide-in confirmation drawer.
6. Completion: Verify the transfer and view updated dashboard balance.

🏆 Definition of Done Checklist

  • App launches with zero compile or console errors.
  • Dashboard displays realistic accounts, balances and statistics.
  • All charts render properly and update on data reload.
  • Siraj AI chat resolves user intent queries (spending overview, transfers, help).
  • Transfer verification triggers modal window and handles actions.
  • Backup local workflow works when API endpoints fail.
  • Demo flow rehearsed at least 3 times.
