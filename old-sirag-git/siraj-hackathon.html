🚀 GitHub Pages Deployment

Quick setup: 5 minutes
Pro Tip: Deploy this page in 5 minutes to get a live shareable link for your entire team!

Step-by-step setup (No coding required)

  • 1
    Create GitHub repository

    Go to github.com/new

  • 2
    Upload siraj-hackathon.html

    Click "Add file" → "Upload files" → Drag & drop file → Commit

  • 3
    Enable GitHub Pages

    Settings → Pages → Source: main branch, Folder: / (root) → Save

  • 4
    Get your live link

    https://USERNAME.github.io/siraj-hackathon/siraj-hackathon.html
