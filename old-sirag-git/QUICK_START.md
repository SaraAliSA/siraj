## 🆘 IF YOU GET STUCK

### "AI responses are too robotic"
→ Add more warmth to system prompt
→ Include Saudi dialect examples
→ Use shorter sentences
→ Start with positives always

### "API is too slow"
→ Add caching layer (Redis or in-memory)
→ Optimize database queries
→ Cache health score (5 min TTL)
→ Use connection pooling

### "Frontend looks bland"
→ Use Tailwind components
→ Add color gradients
→ Use Lucide icons
→ Add subtle animations (CSS only)

### "Deployment fails at last minute"
→ Have backup deployment (GitHub Pages for frontend)
→ Deploy early, not the night before
→ Test production build locally first
→ Have team member on deployment duty

### "Out of time"
→ Skip authentication (use hardcoded user)
→ Skip subscriptions detection (show static list)
→ Skip seasonal planner (show one hardcoded example)
→ Focus on: Dashboard + Health Score + AI Coach

## 📚 ADDITIONAL RESOURCES

**To test system prompt:**
```bash
# Create Python test file
python3 << 'EOF'
import anthropic

client = anthropic.Anthropic()

# Load system prompt from file
with open('siraj_ai_system_prompt.md') as f:
    system_prompt = f.read()

# Test with sample question
response = client.messages.create(
    model="claude-opus-4-6",
    max_tokens=1024,
    system=system_prompt,
    messages=[{
        "role": "user",
        "content": "هل أقدر أشتري سيارة؟"
    }]
)

print(response.content[0].text)
EOF
```

**To seed database:**
```bash
cd siraj-backend
python -m app.db.seed
```

**To start both servers:**
```bash
# Terminal 1 - Backend
cd siraj-backend && python app/main.py

# Terminal 2 - Frontend
cd siraj-frontend && npm start
```
