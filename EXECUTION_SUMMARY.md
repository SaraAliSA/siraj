## ⚠️ COMMON PITFALLS (Avoid These!)

| Pitfall | Why Bad | Prevention |
|---------|---------|-----------|
| **Overbuilding** | Runs out of time | MVP only - 5 pages max |
| **Authentication** | Wastes 4+ hours | Use hardcoded user ID |
| **Custom UI framework** | Learning curve kills you | Use Tailwind (proven) |
| **Real bank APIs** | Auth/integration nightmare | Use mock data |
| **Live coding demo** | Always breaks | Record backup video |
| **Late deployment** | Last-minute stress | Deploy by hour 14 |
| **Ignoring mobile** | 50% of users on phones | Test on actual phone |
| **Generic AI responses** | Not impressive | Add Saudi dialect + warmth |
| **No git commits** | Can't track progress | Commit every 2 hours |
| **Scope creep** | Never finishes | Lock MVP scope day 1 |
